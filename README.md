# Topology-Biased Graph Transformer with Similarity Suppression for 3D Visual Grounding

# Abstrat
[Figure_2_framework.pdf](https://github.com/user-attachments/files/32781900/Figure_2_framework.pdf)
3D visual grounding aims to localize target object in 3D point clouds based on natural language descriptions. 
Although existing transformer-based methods have made significant progress, they often suffered from the problem of "instance confusion", failing to distinguish the target from other objects of the same semantic category in complex scenes. To address this critical problem, we propose a novel Topology-Biased Graph Transformer that solves the instance confusion dilemma from the perspectives of feature representation and loss constraints. Firstly, we introduced a graph-structured transformer to deeply interact with visual and linguistic information. By encoding the visual graph topology structure and text syntax rules through a Topology-Biased Graph Attention (TopGA) module, our model can effectively enrich object features with detailed descriptive attributes and holistic scene layout, and thereby learn highly discriminative representations. Second, to further eliminate false positives during prediction, we design an Attribute and Relation-Guided Similarity Suppression (ARS) Loss. By decoupling object class semantics from spatial relations and attributes, this loss acts as a strict decision-level constraint that actively suppresses intra-class distractors by penalizing mismatched modifiers and relationships. Extensive experiments on standard 3D visual grounding benchmarks, ScanRefer and ReferIt3D, demonstrate the effectiveness of our Topology-Biased Graph Transformer. The results show that our method significantly mitigates instance confusion and exhibits strong robustness in complex, multi-object scenarios.
